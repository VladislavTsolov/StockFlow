# \# StockFlow

# 

#### StockFlow is an ASP.NET Core MVC web application for managing an establishment's stock inventory. It helps track products, record and save deliveries and keep stock quantities up to date.

# 

## \## Features

## 

* #### \*\*Product Management:\*\* Create, view, edit, and delete products.
* #### &#x20;\*\*Inventory Tracking:\*\* Store product names, categories, prices, and available quantities.
* #### &#x20;\*\*Delivery Management:\*\* Record and track deliveries.



## \## Technologies used

# 

* #### \*\*C#
* #### \*\*ASP.NET Core MVC
* #### \*\*Entity Framework Core
* #### \*\*Microsoft SQL Server LocalDB
* #### \*\*Razor Views
* #### \*\*Bootstrap
* #### \*\*HTML and CSS

# 

## \## Requirements

# 

### To run StockFlow locally, you need:

# 

* #### \*\*.NET8 SDK
* #### \*\*Visual Studio with ASP.NET and web development support
* #### \*\*SQL Server LocalDB

# 

## \## Setup and Running

# 

#### 1\. Clone or download the repository.

#### 2\. Open the solution in Visual Studio.

#### 3\. Check the database connection string in "appsettings.json".

#### 4\. Open the Package Manager Console in Visual Studio.

#### 5\. Apply the Entity Framework Core migration using: "Update-Database"

#### 6\. Build and run the project.

# 

## \## Database

# 

#### StockFlow uses Entity Framework Core with SQL Server LocalDB. Database migrations determine the database scheme.

#
